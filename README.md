# Backclip — Fabric 1.21.11

Жезл клиппинга: вставляйте любой декоративный блок (в том числе из других модов) «внутрь» другого блока.

- ПКМ по блоку (блок в левой руке) — поставить декор в клетку у этой грани и утопить в блок.
- Shift + ПКМ по блоку — убрать ближайший декор (блок вернётся в инвентарь).
- ПКМ по воздуху — изменить параметр (глубина / поворот / наклон / размер).
- Shift + ПКМ по воздуху — выбрать параметр.

Рецепт: эндер-жемчуг + палка по диагонали.
